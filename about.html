AR Based Indoor Navigation for Hospitals

Abstract

This project provides indoor navigation assistance for hospitals using an Augmented Reality inspired interface. Users can choose a department and receive navigation instructions with visual guidance and voice assistance.

Problem Statement

Patients and visitors often struggle to locate departments inside large hospitals. Traditional signboards can be confusing, leading to delays and inconvenience.

Objectives

  • Reduce patient confusion.
  • Provide indoor navigation.
  • Improve hospital accessibility.
  • Offer voice-guided directions.
  • Demonstrate AR navigation concepts.

Technologies Used

Technology Purpose
HTML5 Web Structure
CSS3 User Interface
JavaScript Navigation Logic
Speech Synthesis API Voice Guidance
VS Code Development

Future Scope

  • Unity ARCore Integration
  • Real Camera Navigation
  • AI Route Optimization
  • Voice Commands
  • Cloud Synchronization
  • Multi-floor Navigation

Expected Outcome

Users can quickly navigate hospital departments through an interactive map, animated guidance, and voice instructions. This prototype demonstrates the core workflow of an AR-based hospital navigation system.
